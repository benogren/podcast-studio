# Assets

Optional theme music for `scripts/podcast_audio.py`. Drop in `theme.mp3` (used for both intro
and outro) or `intro.mp3` / `outro.mp3`. The intro plays right after the cold open and the
outro after the sign-off. With no files here the episode is voice-only.

Only use music you have the right to publish with. Record where each file came from and its
